# ZEDECKDEV

Site institucional estático para apresentação de serviços e contato profissional.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. O site será carregado diretamente sem necessidade de instalar dependências, rodar comandos ou executar qualquer servidor.
3. Para clientes, basta acessar a página e escolher o serviço desejado.

## Funcionalidades incluídas

- layout profissional e moderno
- apresentação com nome ZEDECKDEV e efeito 3D na página inicial
- seção de serviços com opção de escolha rápida
- área de projetos em constante atualização
- botão de WhatsApp com animação e número já pré-configurado
- ícones de redes sociais para Instagram, LinkedIn, GitHub e WhatsApp
- design responsivo para desktop e mobile
